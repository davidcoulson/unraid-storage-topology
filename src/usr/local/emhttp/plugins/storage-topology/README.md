**Storage Topology**

Read-only views of your storage and network hardware. Storage: SAS controllers, ports, connectors, cables, disk
shelves (power, cooling, sensors, I/O modules, bays), directly attached drives, USB enclosures, firmware versions and
per-drive link speed and errors, mapped to Unraid disk names (storcli optional, sg_ses). Problems can be acknowledged;
diagnostics can be downloaded (anonymised). Network: physical NICs, PCIe link, ports, FEC, error counters, transceiver modules, bonds,
bridges, VLANs and LLDP neighbours. Tools > System Information > Storage Topology / Network Topology.
