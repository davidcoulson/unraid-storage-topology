**Storage Topology**

Read-only views of your storage and network hardware. Storage: SAS controllers, ports, cables, disk shelves (power,
cooling, sensors, I/O modules, bays), firmware versions and per-drive link speed and errors, mapped to Unraid disk names
(storcli optional, sg_ses). Network: physical NICs, PCIe link, ports, FEC, error counters, transceiver modules, bonds,
bridges, VLANs and LLDP neighbours. Tools > System Information > Storage Topology / Network Topology.
